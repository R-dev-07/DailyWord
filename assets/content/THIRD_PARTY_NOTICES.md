# Third-party content notices

## Bible versions (downloaded on demand)

DailyWord can download any of the 141 Bible versions listed in `bible-versions-index.json` from the `thiagobodruk/bible` repository (https://github.com/thiagobodruk/bible), pinned to the commit recorded in `bible-manifest.json`. The text is fetched by the user's device when they choose a version, stored in the local SQLite database, and never bundled into the app binary. Only the KJV file is bundled.

The repository's code and data files are distributed under the MIT License (copy in `bible-master-LICENSE.txt`). The upstream README separately states that the Bible versions are the property of their respective owners and that all rights are reserved to those owners. The project owner has confirmed they are authorized to use all 141 versions; keep that authorization on file, and review each edition's terms before a public store release, since the MIT license on the repository does not by itself grant rights in the underlying translations.

The upstream project notes that its files were generated by a crawler and may contain minor encoding or syntax issues. Spot-checking is recommended for versions your users read most.
